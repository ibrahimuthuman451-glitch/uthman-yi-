# Official Uthman IY logo

Place the **official Uthman IY blue UY logo** in this folder, unchanged, using one of these file names:

1. `uthman-iy-logo.png` (preferred)
2. `uthman-iy-logo.svg`
3. `uthman-iy-logo.webp`
4. `uthman-iy-logo.jpg`

Rules enforced by the implementation:

- The file is rendered as-is: no regeneration, recolouring, cropping, stretching or overlaying.
- CSS only sets the height (`h-8` / `h-10`) and lets the width follow the file's own aspect ratio.
- Until a file is present, the site shows the company name **Uthman IY** as plain text (a temporary
typographic fallback, not a substitute logo) and the header marks it as pending in the admin dashboard.

No logo file was supplied with the repository, so the official logo is the main outstanding brand asset.
